# Satoshi

Satoshi by Indian Type Foundry, distributed through [Fontshare](https://www.fontshare.com/fonts/satoshi).

Regular (400), Medium (500), and Bold (700) WOFF2 files were obtained from Fontshare's public font CSS endpoint. The site hosts these files locally and uses `font-display: swap`.
